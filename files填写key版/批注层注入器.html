批注与编辑层注入器 单文件版

文件不上传，全部在本地浏览器完成

这两项不内置默认值，必须填自己的 Supabase 项目信息，批注才会同步到数据库、支持跨页面/跨设备可见——填过一次之后这个浏览器会记住，下次打开不用重填。留空的话批注只会保存在本地这份文件里，不会同步、也看不到"项目内其他页面"。

拖入 HTML 原型文件，生成带批注与页面编辑功能的副本。

  • 拖入一个未批注的文件 → 注入批注与编辑层
  • 拖入一个已批注的旧版文件 → 升级到最新版，原有批注全部保留
  • 一次拖入两个（旧的带批注 + 新的原型）→ 把旧批注搬到新原型上
  • 拖入多个互不相关的文件 → 各自独立处理，各自单独下载
点击选择 或 拖入 HTML 文件支持多选 · 两个文件时自动搬运批注

点击选择一整个文件夹（比如 Axure 导出包，或放在同一个文件夹里的多个页面）。文件夹里所有 HTML 共用同一个项目、批注全局可见、编号统一；图片/CSS 等非 HTML 文件原样保留；下载下来还是一个文件夹（打包成 zip，解压即可，文件名和相对路径都不变）。文件夹里没有 index.html 的话会自动生成一个导航外壳，方便打开后在多个页面间切换。

解压后会多一个 annoproject.json，跟 index.html 放在一起——以后在 Axure 里改完原型重新生成 HTML 包，把这份文件也留在同一个文件夹里（Axure 自己不认识它，不会动它），再拖进来批注就不会失联；删了这份文件的话，重新生成后批注就找不回来了。

点击选择文件夹
改版保留批注：把旧的（带批注）和新导出的原型一起拖进来，批注自动搬过去。
打开后看一眼批注清单：结构变动的批注会标黄，点一下即可重新指定元素。
